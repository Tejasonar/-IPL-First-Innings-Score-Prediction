🏏 IPL First Innings Score Prediction

This project predicts the **first innings score** in IPL matches using **Linear Regression**.  
The model is trained on historical IPL data with proper data cleaning, feature selection, and visualization.

 Technologies Used
- Python  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- Scikit-learn  

Features
- Data preprocessing and visualization  
- Linear Regression model training  
- Prediction of first innings score based on input features
